โครงสร้าง Attribute ของตาราง FacultyWorkloads บน DynamoDB ถูกออกแบบโดยอิงจากโครงสร้าง JSON เดิมใน V2 ผสมผสานกับฟิลด์ที่จำเป็นสำหรับการจัดการระบบ Workflow ใน V3 โดยแบ่งเป็นระดับชั้นข้อมูลหลัก (Root) และข้อมูลภาระงานที่เก็บเป็น List ดังนี้

1. Root Attributes (แอตทริบิวต์ระดับบนสุด)
ข้อมูลส่วนนี้ใช้สำหรับการค้นหา การอ้างอิง และการจัดการสถานะของเอกสารในฐานข้อมูล:

faculty_id (String) - Partition Key: รหัสประจำตัวอาจารย์ (เช่น "prof_001")

term_id (String) - Sort Key: รหัสปีการศึกษาและภาคการศึกษาที่นำมาเชื่อมต่อกัน (เช่น "2567#1")

workflow_status (String): สถานะปัจจุบันของการส่งข้อมูลภาระงาน (เช่น "Draft", "Pending_Review", "Approved", "Rejected")

academic_year (Number): ปีการศึกษา (เช่น 2567)

semester (Number): ภาคการศึกษา (เช่น 1)

evaluation_period (String): ช่วงเวลารอบการประเมิน (เช่น "1 กรกฎาคม 2567 - 31 ธันวาคม 2567")

2. Workloads Attribute (แอตทริบิวต์กลุ่มภาระงาน)
ฟิลด์ชื่อ workloads จะถูกกำหนดให้เป็นชนิด Map (Object) ซึ่งทำหน้าที่เหมือนกล่องบรรจุหมวดหมู่งานย่อย 4 หมวด โดยแต่ละหมวดจะถูกเก็บเป็นชนิด List (Array of Objects) เนื่องจากใน 1 ภาคการศึกษา อาจารย์ 1 ท่านสามารถมีรายการงานในแต่ละหมวดได้มากกว่า 1 รายการ:

teaching (List): แอตทริบิวต์สำหรับเก็บข้อมูลงานสอน

โครงสร้าง Object ภายใน List: ประกอบด้วย course_code (รหัสวิชา), course_type (ประเภทวิชา เช่น วิชาบรรยาย/ปฏิบัติการ), credits (หน่วยกิต), hours (ชั่วโมง), teaching_ratio (สัดส่วนการสอน)

student_advising / professional_development (List): แอตทริบิวต์สำหรับเก็บข้อมูลงานที่ปรึกษานักศึกษา โครงงาน วิทยานิพนธ์ หรือการพัฒนาวิชาชีพ

โครงสร้าง Object ภายใน List: ประกอบด้วย advising_type (ประเภทการให้คำปรึกษา), course_code (รหัสวิชา), student_or_project_detail (ชื่อนักศึกษาหรือจำนวนเรื่อง), role (บทบาท เช่น ที่ปรึกษาหลัก), count_or_credits (จำนวนหรือหน่วยกิต)

academic_outputs / research (List): แอตทริบิวต์สำหรับเก็บข้อมูลงานวิจัย บทความวิชาการ หรือผลงานตีพิมพ์

โครงสร้าง Object ภายใน List: ประกอบด้วย output_type (ประเภทผลงาน), title (ชื่อผลงาน), participation_percentage (สัดส่วนการมีส่วนร่วม), category (ระดับการตีพิมพ์)

services_and_admin / academic_service (List): แอตทริบิวต์สำหรับเก็บข้อมูลงานบริหารวิชาการและบริการสังคม

โครงสร้าง Object ภายใน List: ประกอบด้วย service_category (หมวดหมู่งานบริการ), role (ตำแหน่งหรือหน้าที่), detail (รายละเอียดงาน)
